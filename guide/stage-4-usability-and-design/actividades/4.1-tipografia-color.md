## Por que esta actividad

Abrir un editor y elegir "font-size: 18px" para un titulo, "14px" para un parrafo y "12px" para un caption parece inofensivo. Pero sin un sistema, cada desarrollador del equipo elige numeros diferentes, los tamanos se acumulan sin lógica, y la interfaz se siente inconsistente — el usuario no sabe que es importante y que no. Lo mismo pasa con el color: elegir colores "a ojo" produce interfaces donde el texto no tiene suficiente contraste para ser legible, o donde el botón de error se ve igual que el de exito.

Un **type scale** (escala tipografica) y una **paleta sistematica** resuelven esto. Defines las reglas una vez y todo el equipo las sigue.

## Antes de empezar

Necesitas haber completado la **Etapa 3**. Vas a trabajar sobre tu proyecto existente o crear un archivo HTML nuevo para experimentar.

Conceptos clave que debes conocer:

- **Type scale** (escala tipografica): un conjunto de tamanos de texto que crecen siguiendo una proporción matematica. En lugar de elegir tamanos arbitrarios (12px, 15px, 18px, 22px), defines una base (por ejemplo, 1rem = 16px) y un ratio (por ejemplo, 1.25). Cada nivel se multiplica por el ratio: 1rem, 1.25rem, 1.563rem, 1.953rem... Esto crea una jerarquia visual armonica que el ojo percibe como "bien disenada".
- **Custom properties** (variables CSS): valores que defines una vez y reutilizas. Se escriben `--nombre: valor` y se usan `var(--nombre)`. Si cambias el valor en un solo lugar, cambia en toda la aplicación.
- **`clamp()`**: una función CSS que define un tamaño minimo, un tamaño ideal (fluido), y un tamaño maximo. Ejemplo: `clamp(1rem, 2vw + 0.5rem, 1.5rem)` — nunca sera menor a 1rem ni mayor a 1.5rem, pero se adapta al ancho de la pantalla.
- **Paleta de 3 capas**: una forma de organizar colores por función: brand (la identidad visual), neutral (grises para texto y fondos), semantic (rojo para error, verde para exito, amarillo para advertencia).

### Paso 1 — Crear archivos

1. En tu proyecto, crea una carpeta `ejercicio-4.1`
2. Crea un archivo `index.html` con esta estructura:

```text
<!-- HTML: esqueleto basico para probar el sistema tipografico -->
<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Sistema Tipografico y Color</title>
  <link rel="stylesheet" href="tokens.css">
  <link rel="stylesheet" href="styles.css">
</head>
<body>
  <header>
    <h1>Dashboard de Ventas</h1>
    <p class="subtitle">Resumen mensual — Marzo 2026</p>
  </header>
  <main>
    <section>
      <h2>Metricas principales</h2>
      <p>Estos son los resultados del ultimo trimestre.</p>
      <div class="card card--success">
        <h3>Ventas totales</h3>
        <p class="metric">$124,500</p>
        <p class="caption">+12% vs mes anterior</p>
      </div>
      <div class="card card--warning">
        <h3>Tasa de conversion</h3>
        <p class="metric">3.2%</p>
        <p class="caption">-0.5% vs mes anterior</p>
      </div>
      <div class="card card--error">
        <h3>Tickets sin resolver</h3>
        <p class="metric">47</p>
        <p class="caption">Requiere atencion</p>
      </div>
    </section>
  </main>
</body>

```

3. Crea un archivo `tokens.css` (aquí iran las variables)
4. Crea un archivo `styles.css` (aquí ira el estilo visual)

### Paso 2 — Definir el type scale

1. Abre `tokens.css`
2. Define el type scale con ratio 1.25 (llamado "Major Third"). Cada nivel es el anterior multiplicado por 1.25:

```css
/* tokens.css — Sistema tipografico */
:root {
  /* Base: 1rem = 16px en la mayoria de navegadores */
  --font-size-sm: clamp(0.8rem, 0.17vw + 0.76rem, 0.89rem);
  --font-size-base: clamp(1rem, 0.34vw + 0.91rem, 1.19rem);
  --font-size-md: clamp(1.25rem, 0.61vw + 1.1rem, 1.58rem);
  --font-size-lg: clamp(1.56rem, 1vw + 1.31rem, 2.11rem);
  --font-size-xl: clamp(1.95rem, 1.56vw + 1.56rem, 2.81rem);
  --font-size-2xl: clamp(2.44rem, 2.38vw + 1.85rem, 3.75rem);

  /* Line heights — mas grandes para texto, mas apretados para titulos */
  --line-height-tight: 1.2;
  --line-height-normal: 1.5;
  --line-height-relaxed: 1.75;

  /* Font weights */
  --font-weight-normal: 400;
  --font-weight-medium: 500;
  --font-weight-bold: 700;
}
```

> 💡 **Nota:** Los valores de `clamp()` fueron calculados con herramientas como [Utopia](https://utopia.fyi/type/calculator/). No necesitas calcularlos a mano — lo importante es entender que el tamaño minimo protege la legibilidad en móvil y el maximo evita que los titulos sean gigantes en pantallas grandes.

### Paso 3 — Aplicar la tipografia

1. Abre `styles.css`
2. Usa las variables para cada nivel de texto:

```css
/* styles.css — Aplicar el type scale */
body {
  font-family: system-ui, -apple-system, sans-serif;
  font-size: var(--font-size-base);
  line-height: var(--line-height-normal);
  color: var(--color-text);
  background-color: var(--color-surface);
}

h1 {
  font-size: var(--font-size-2xl);
  font-weight: var(--font-weight-bold);
  line-height: var(--line-height-tight);
}

h2 {
  font-size: var(--font-size-xl);
  font-weight: var(--font-weight-bold);
  line-height: var(--line-height-tight);
}

h3 {
  font-size: var(--font-size-lg);
  font-weight: var(--font-weight-medium);
  line-height: var(--line-height-tight);
}

.subtitle {
  font-size: var(--font-size-md);
  font-weight: var(--font-weight-normal);
}

.metric {
  font-size: var(--font-size-xl);
  font-weight: var(--font-weight-bold);
}

.caption {
  font-size: var(--font-size-sm);
  line-height: var(--line-height-relaxed);
}
```

3. Abre la página en el navegador con Live Server. Redimensiona la ventana — los tamanos de texto deben cambiar fluidamente entre el minimo y el maximo.

### Paso 4 — Crear la paleta de color

1. Vuelve a `tokens.css`
2. Agrega las 3 capas de color despues de la tipografia:

```css
  /* ========== PALETA DE COLOR ========== */

  /* Capa 1: Brand — la identidad visual */
  --color-brand-50: #eff6ff;
  --color-brand-100: #dbeafe;
  --color-brand-500: #3b82f6;
  --color-brand-700: #1d4ed8;
  --color-brand-900: #1e3a5f;

  /* Capa 2: Neutral — grises para texto, fondos, bordes */
  --color-neutral-50: #fafafa;
  --color-neutral-100: #f5f5f5;
  --color-neutral-200: #e5e5e5;
  --color-neutral-400: #a3a3a3;
  --color-neutral-600: #525252;
  --color-neutral-800: #262626;
  --color-neutral-900: #171717;

  /* Capa 3: Semantic — significado funcional */
  --color-success: #16a34a;
  --color-warning: #ca8a04;
  --color-error: #dc2626;
  --color-info: #2563eb;

  /* Tokens funcionales — conectan capas con uso */
  --color-text: var(--color-neutral-900);
  --color-text-muted: var(--color-neutral-600);
  --color-surface: var(--color-neutral-50);
  --color-surface-raised: #ffffff;
  --color-border: var(--color-neutral-200);
  --color-primary: var(--color-brand-500);
  --color-primary-hover: var(--color-brand-700);
```

3. En `styles.css`, agrega estilos para las tarjetas semanticas:

```css
.card {
  background-color: var(--color-surface-raised);
  border: 1px solid var(--color-border);
  border-radius: 0.5rem;
  padding: 1.5rem;
  margin-block: 1rem;
}

.card--success { border-left: 4px solid var(--color-success); }
.card--warning { border-left: 4px solid var(--color-warning); }
.card--error { border-left: 4px solid var(--color-error); }

.caption {
  color: var(--color-text-muted);
}
```

### Paso 5 — Dark mode

1. Al final de `tokens.css`, agrega un media query que redefine los tokens funcionales:

```css
@media (prefers-color-scheme: dark) {
  :root {
    --color-text: var(--color-neutral-100);
    --color-text-muted: var(--color-neutral-400);
    --color-surface: var(--color-neutral-900);
    --color-surface-raised: var(--color-neutral-800);
    --color-border: var(--color-neutral-600);
    --color-primary: var(--color-brand-100);
    --color-primary-hover: var(--color-brand-50);
  }
}
```

> 💡 **Nota:** Solo redefiniste los tokens funcionales (text, surface, border), no los colores base. Las 3 capas (brand, neutral, semantic) no cambian — lo que cambia es como se asignan. Esta separacion es la clave del sistema.

2. Para probar dark mode sin cambiar la configuración de tu sistema:
   - En Chrome: DevTools → Rendering (busca en el menu de 3 puntos → More tools → Rendering) → "Emulate CSS media feature prefers-color-scheme" → dark
   - En Firefox: DevTools → Inspector → en la barra de herramientas hay un icono de sol/luna

### Paso 6 — Verificar contraste

1. En Chrome DevTools, selecciona cualquier texto de tu página
2. En el panel de Styles, haz clic en el cuadrado de color junto a `color`
3. DevTools muestra el **contrast ratio** — debe ser al menos **4.5:1** para texto normal y **3:1** para texto grande (>18pt o >14pt bold)
4. Repite para modo oscuro — los tokens funcionales deben mantener el contraste
5. Si algun contraste falla, ajusta el tono del token correspondiente (generalmente necesitas un gris mas claro para texto en fondo oscuro)

## Que puede salir mal

- **"Los tamanos de texto no cambian cuando redimensiono la ventana"** → Verifica que usaste `clamp()` en los custom properties. Si escribiste `--font-size-base: 1rem` sin clamp, el tamaño es fijo. Revisa que el archivo `tokens.css` esta enlazado correctamente en el HTML (`<link rel="stylesheet" href="tokens.css">`).
- **"No veo diferencia entre dark mode y light mode"** → Asegura que los tokens funcionales (--color-text, --color-surface) estan dentro del `@media (prefers-color-scheme: dark)`. Si definiste colores directos en styles.css (por ejemplo, `color: #171717`), esos no cambian — deben usar `var(--color-text)`.
- **"DevTools dice que el contraste es insuficiente"** → Ajusta el token. Para dark mode, el texto suele necesitar ser `--color-neutral-100` o mas claro. No uses blanco puro (#ffffff) sobre negro puro (#000000) — es demasiado contraste y causa fatiga visual.

## Resultado esperado

Tu página muestra contenido con una jerarquia tipografica clara: titulos grandes que disminuyen progresivamente, texto base legible, captions pequenos en gris. Las tarjetas tienen bordes de color semántico (verde, amarillo, rojo). Al activar dark mode en DevTools, los colores se invierten armonicamente manteniendo la legibilidad.

**Criterios de aceptacion:**
- [ ] Type scale definido con custom properties y `clamp()` — cero valores `px` en font sizes
- [ ] Paleta con las 3 capas (brand, neutral, semantic) en custom properties
- [ ] Dark mode funciona con `prefers-color-scheme` — activarlo en DevTools cambia los colores
- [ ] Contraste texto/fondo cumple WCAG AA (4.5:1) en ambos modos — verificado en DevTools
