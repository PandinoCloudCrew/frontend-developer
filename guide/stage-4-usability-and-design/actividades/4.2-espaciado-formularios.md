# 🟢 Actividad 4.2 — Implementar sistema de espaciado y disenar formularios

[Inicio](../../README.md) > [Etapa 4](../README.md) > Actividad 4.2

**Duracion:** ~55 min

## Por que esta actividad

Un formulario de 20 campos en una sola pantalla abruma al usuario. Un botón de "Enviar" que valida todo al final obliga al usuario a buscar que campo fallo. Y cuando el espaciado entre elementos no sigue un patrón consistente, la interfaz se siente desordenada aunque tecnicamente funcione.

El sistema de espaciado (un grid base de 8px con tokens predefinidos) elimina las decisiones arbitrarias de margenes y paddings. El patrón de formulario wizard divide los 20 campos en pasos manejables. La validación inline (que ocurre cuando el usuario sale del campo, no cuando hace submit) le dice inmediatamente si algo esta mal. Juntos, estos tres conceptos transforman formularios de "funciona" a "es agradable de usar".

## Antes de empezar

Necesitas haber completado la **Actividad 4.1** (ya tienes `tokens.css` con tipografia y color).

Conceptos clave:

- **Grid de 8px**: una regla de diseño donde todos los espaciados son multiplos de 8: 8px (0.5rem), 16px (1rem), 24px (1.5rem), 32px (2rem), 48px (3rem)... Esto crea consistencia visual porque el ojo humano percibe los patrones regulares como "ordenados".
- **Token de espaciado**: un custom property como `--space-2: 0.5rem` que usas en lugar de escribir `margin: 8px`. Si decides que tu grid base es 4px en vez de 8px, cambias los tokens y todo se actualiza.
- **Validación inline on-blur**: validar cada campo cuando el usuario sale de el (evento `blur`), no cuando hace clic en "Enviar". El usuario recibe feedback inmediato sin que lo interrumpan mientras escribe.
- **Wizard multi-paso**: dividir un formulario largo en pasos cortos (3-5 campos por paso). El usuario ve un paso a la vez con un indicador de progreso que le dice cuanto falta.

2. Agrega los tokens de espaciado despues de la paleta de color:

```css
  /* ========== ESPACIADO ========== */
  /* Grid base: 8px (0.5rem) */
  --space-1: 0.25rem;   /* 4px — micro separaciones */
  --space-2: 0.5rem;    /* 8px — padding interno */
  --space-3: 0.75rem;   /* 12px */
  --space-4: 1rem;      /* 16px — separacion estandar */
  --space-6: 1.5rem;    /* 24px — entre grupos */
  --space-8: 2rem;      /* 32px — entre secciones */
  --space-12: 3rem;     /* 48px — entre bloques grandes */
  --space-16: 4rem;     /* 64px — margen de pagina */
```

### Paso 4 — Indicador de progreso

El HTML y CSS del paso anterior ya incluyen el indicador de progreso. Lo que falta es actualizarlo con JavaScript cuando el usuario navega entre pasos.

### Paso 5 — Navegación entre pasos

1. Crea `wizard.js`:

```javascript
// wizard.js — Logica de navegacion del wizard
const form = document.getElementById('wizard-form');
const steps = document.querySelectorAll('.wizard-step');
const stepIndicators = document.querySelectorAll('.step');
const progressFill = document.querySelector('.progress-fill');
const btnPrev = document.getElementById('btn-prev');
const btnNext = document.getElementById('btn-next');
const btnSubmit = document.getElementById('btn-submit');

let currentStep = 0;
const totalSteps = steps.length;

function showStep(index) {
  steps.forEach((step, i) => {
    step.classList.toggle('active', i === index);
  });

  stepIndicators.forEach((indicator, i) => {
    indicator.classList.toggle('active', i === index);
    indicator.classList.toggle('completed', i < index);
    if (i === index) {
      indicator.setAttribute('aria-current', 'step');
    } else {
      indicator.removeAttribute('aria-current');
    }
  });

  // Actualizar barra de progreso
  const progress = ((index + 1) / totalSteps) * 100;
  progressFill.style.width = `${progress}%`;

  // Mostrar/ocultar botones
  btnPrev.hidden = index === 0;
  btnNext.hidden = index === totalSteps - 1;
  btnSubmit.hidden = index !== totalSteps - 1;
}

function validateCurrentStep() {
  const currentFieldset = steps[currentStep];
  const inputs = currentFieldset.querySelectorAll('input, select');
  let isValid = true;

  inputs.forEach((input) => {
    if (!input.checkValidity()) {
      showFieldError(input);
      isValid = false;
    }
  });

  return isValid;
}

btnNext.addEventListener('click', () => {
  if (validateCurrentStep() && currentStep < totalSteps - 1) {
    currentStep++;
    showStep(currentStep);
  }
});

btnPrev.addEventListener('click', () => {
  if (currentStep > 0) {
    currentStep--;
    showStep(currentStep);
  }
});

form.addEventListener('submit', (event) => {
  event.preventDefault();
  if (validateCurrentStep()) {
    alert('Formulario enviado correctamente');
  }
});

// Inicializar
showStep(0);
```

### Paso 6 — Validación inline

1. Agrega la lógica de validación al final de `wizard.js`:

```javascript
// ========== Validacion inline on-blur ==========

function showFieldError(input) {
  const errorElement = input.closest('.field')?.querySelector('.field-error');
  if (!errorElement) return;

  input.closest('.field').classList.add('has-error');

  if (input.validity.valueMissing) {
    errorElement.textContent = 'Este campo es obligatorio';
  } else if (input.validity.typeMismatch) {
    errorElement.textContent = 'El formato no es valido';
  } else if (input.validity.tooShort) {
    errorElement.textContent = `Minimo ${input.minLength} caracteres`;
  } else if (input.validity.patternMismatch) {
    errorElement.textContent = input.title || 'El formato no es correcto';
  } else {
    errorElement.textContent = '';
    input.closest('.field').classList.remove('has-error');
  }
}

function clearFieldError(input) {
  const errorElement = input.closest('.field')?.querySelector('.field-error');
  if (errorElement && input.checkValidity()) {
    errorElement.textContent = '';
    input.closest('.field').classList.remove('has-error');
  }
}

// Validar al salir del campo (blur)
document.querySelectorAll('.field input, .field select').forEach((input) => {
  input.addEventListener('blur', () => showFieldError(input));
  input.addEventListener('input', () => clearFieldError(input));
});
```

> 💡 **Nota:** Usamos `blur` (cuando el usuario sale del campo) en vez de `input` (mientras escribe) para mostrar errores. Validar mientras escribe es frustrante — imagina que el campo dice "correo invalido" mientras aun estas escribiendo tu email. En cambio, limpiar el error mientras escribe (el listener de `input`) da feedback positivo inmediato.

## Que puede salir mal

- **"No puedo avanzar al siguiente paso"** → Revisa la consola del navegador (F12 → Console). Si hay un error de JavaScript, el botón no funciona. Los errores mas comunes son: no encontrar un elemento (`querySelector` devolvio `null`) o un typo en el nombre de la clase.
- **"El error no desaparece aunque corrija el campo"** → Verifica que el listener de `input` esta llamando a `clearFieldError`. Si solo tienes el listener de `blur`, el error se mantiene hasta que el usuario sale y vuelve a entrar al campo.
- **"Los campos del paso 2 se ven aunque estoy en el paso 1"** → Asegurate de que `.wizard-step` tiene `display: none` en CSS y solo `.wizard-step.active` tiene `display: block`. Si pusiste el estilo en el orden incorrecto, el `display: block` del fieldset por defecto del navegador puede ganar.
- **"Todo el espaciado se ve comprimido"** → Verifica que el `<link>` a `tokens.css` esta antes del `<link>` a `styles.css` en el HTML, y que la ruta es correcta (relativa a la carpeta del ejercicio).

## Resultado esperado

Tu formulario muestra un paso a la vez con un indicador de progreso en la parte superior. Al salir de un campo obligatorio vacio, aparece un mensaje de error rojo debajo. Al corregir el campo, el error desaparece. Los botones "Anterior" y "Siguiente" permiten navegar entre pasos. En el ultimo paso, el botón "Siguiente" se reemplaza por "Crear cuenta".

**Criterios de aceptacion:**
- [ ] Todos los margenes, paddings y gaps usan tokens de espaciado (`var(--space-*)`) — cero valores directos
- [ ] El wizard muestra progreso y permite retroceder con el botón "Anterior"
- [ ] Validación ocurre al blur, no al submit — probarlo dejando un campo obligatorio vacio y saliendo con Tab
- [ ] Botón "Siguiente" solo avanza si los campos del paso actual son validos
