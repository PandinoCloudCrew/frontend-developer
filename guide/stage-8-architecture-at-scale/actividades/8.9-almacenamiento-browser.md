## Por que esta actividad

`localStorage` es la opcion por defecto cuando necesitas guardar datos en el navegador, pero tiene limitaciones serias: es sincrono (bloquea el main thread), solo almacena strings, y tiene un limite de ~5 MB. Para datos estructurados, operaciones CRUD reales, o apps que funcionan offline, necesitas **IndexedDB** — una base de datos transaccional en el navegador que almacena objetos JavaScript nativos, soporta indices para queries rapidas, y puede manejar cientos de megabytes. En esta actividad vas a construir un servicio Angular que encapsula IndexedDB con signals, implementando operaciones CRUD reales y un patron de cache que funciona como fallback cuando la API no esta disponible.

## Antes de empezar

Necesitas tener completada la **Actividad 8.8** (validacion integral de la Etapa 8) y entender como funcionan signals y servicios en Angular.

**IndexedDB** es una base de datos NoSQL en el navegador. A diferencia de `localStorage`, es asincrona (no bloquea el main thread), almacena objetos JavaScript directamente (no solo strings), y soporta indices para buscar eficientemente por campos.

**`idb`** es una libreria que envuelve la API nativa de IndexedDB (basada en eventos) en Promises modernas. Sin ella, la API es verbosa y propensa a errores.

**Object store** es el equivalente a una tabla en una base de datos relacional. Cada store tiene un key path (campo que sirve como ID unico).

**Transaction** es un grupo de operaciones que se ejecutan atomicamente — si algo falla, todo se revierte. Es la forma segura de hacer operaciones en lote.

### Paso 2 — Crear el servicio de store con signals

1. Genera el servicio:
   ```bash
   ng generate service services/tarea-store
   ```
2. En `src/app/services/tarea-store.service.ts`:
   ```typescript
   import { Injectable, signal, computed } from '@angular/core';
   import { openDB, IDBPDatabase } from 'idb';

   export interface Tarea {
     id: string;
     titulo: string;
     descripcion: string;
     completada: boolean;
     creadaEn: number;
     actualizadaEn: number;
   }

   @Injectable({ providedIn: 'root' })
   export class TareaStoreService {
     private db!: IDBPDatabase;
     private tareas = signal<Tarea[]>([]);

     // Computed signals derivados
     todas = computed(() => this.tareas());
     pendientes = computed(() => this.tareas().filter(t => !t.completada));
     completadas = computed(() => this.tareas().filter(t => t.completada));
     totalPendientes = computed(() => this.pendientes().length);

     async inicializar(): Promise<void> {
       this.db = await openDB('mi-app-tareas', 1, {
         upgrade(db) {
           const store = db.createObjectStore('tareas', { keyPath: 'id' });
           store.createIndex('completada', 'completada');
           store.createIndex('creadaEn', 'creadaEn');
         },
       });
       await this.recargar();
     }

     private async recargar(): Promise<void> {
       const todas = await this.db.getAll('tareas');
       todas.sort((a, b) => b.creadaEn - a.creadaEn); // Mas recientes primero
       this.tareas.set(todas);
     }
   }
   ```

> 💡 **Nota:** El primer parametro de `openDB` es el nombre de la base de datos, el segundo es la version. Al incrementar la version, se ejecuta el callback `upgrade` donde puedes crear o modificar object stores e indices. El indice `completada` permite buscar tareas por estado sin recorrer todas.

### Paso 3 — Implementar CRUD completo

1. Agrega los metodos CRUD al `TareaStoreService` (despues del metodo `recargar`):
   ```typescript
   async agregar(titulo: string, descripcion: string = ''): Promise<Tarea> {
     const tarea: Tarea = {
       id: crypto.randomUUID(),
       titulo,
       descripcion,
       completada: false,
       creadaEn: Date.now(),
       actualizadaEn: Date.now(),
     };
     await this.db.put('tareas', tarea);
     await this.recargar();
     return tarea;
   }

   async actualizar(id: string, cambios: Partial<Omit<Tarea, 'id' | 'creadaEn'>>): Promise<void> {
     const tarea = await this.db.get('tareas', id);
     if (!tarea) throw new Error(`Tarea ${id} no encontrada`);

     const actualizada = {
       ...tarea,
       ...cambios,
       actualizadaEn: Date.now(),
     };
     await this.db.put('tareas', actualizada);
     await this.recargar();
   }

   async toggleCompletada(id: string): Promise<void> {
     const tarea = await this.db.get('tareas', id);
     if (!tarea) throw new Error(`Tarea ${id} no encontrada`);

     await this.actualizar(id, { completada: !tarea.completada });
   }

   async eliminar(id: string): Promise<void> {
     await this.db.delete('tareas', id);
     await this.recargar();
   }

   async obtenerPorEstado(completada: boolean): Promise<Tarea[]> {
     return this.db.getAllFromIndex('tareas', 'completada', completada ? 1 : 0);
   }

   async eliminarCompletadas(): Promise<void> {
     const completadas = this.completadas();
     const tx = this.db.transaction('tareas', 'readwrite');
     await Promise.all([
       ...completadas.map(t => tx.store.delete(t.id)),
       tx.done,
     ]);
     await this.recargar();
   }
   ```

2. Crea un componente para probar el CRUD:
   ```bash
   ng generate component tarea-list
   ```
3. En `src/app/tarea-list/tarea-list.component.ts`:
   ```typescript
   import { Component, inject, OnInit, signal } from '@angular/core';
   import { FormsModule } from '@angular/forms';
   import { TareaStoreService } from '../services/tarea-store.service';

   @Component({
     selector: 'app-tarea-list',
     standalone: true,
     imports: [FormsModule],
     template: `
       <div class="container">
         <h2>Tareas ({{ store.totalPendientes() }} pendientes)</h2>

         <form (submit)="agregar($event)">
           <input
             [(ngModel)]="nuevoTitulo"
             name="titulo"
             placeholder="Nueva tarea..."
             required
           />
           <button type="submit">Agregar</button>
         </form>

         @for (tarea of store.todas(); track tarea.id) {
           <div class="tarea" [class.completada]="tarea.completada">
             <input
               type="checkbox"
               [checked]="tarea.completada"
               (change)="store.toggleCompletada(tarea.id)"
             />
             <span>{{ tarea.titulo }}</span>
             <button (click)="store.eliminar(tarea.id)">Eliminar</button>
           </div>
         } @empty {
           <p>No hay tareas. Agrega una para empezar.</p>
         }

         @if (store.completadas().length > 0) {
           <button (click)="store.eliminarCompletadas()">
             Limpiar completadas ({{ store.completadas().length }})
           </button>
         }
       </div>
     `,
     styles: [`
       .container { max-width: 500px; margin: 2rem auto; padding: 1rem; }
       form { display: flex; gap: 0.5rem; margin-bottom: 1rem; }
       input[type="text"], input:not([type]) {
         flex: 1; padding: 0.5rem; border: 1px solid #cbd5e1; border-radius: 4px;
       }
       .tarea { display: flex; align-items: center; gap: 0.5rem; padding: 0.5rem 0; }
       .tarea.completada span { text-decoration: line-through; color: #94a3b8; }
       button { padding: 0.25rem 0.75rem; border-radius: 4px; cursor: pointer; }
     `],
   })
   export class TareaListComponent implements OnInit {
     store = inject(TareaStoreService);
     nuevoTitulo = '';

     async ngOnInit() {
       await this.store.inicializar();
     }

     async agregar(event: Event) {
       event.preventDefault();
       if (this.nuevoTitulo.trim()) {
         await this.store.agregar(this.nuevoTitulo.trim());
         this.nuevoTitulo = '';
       }
     }
   }
   ```
4. Agrega una ruta para el componente o incluyelo en tu app. Prueba el CRUD:

   - Marcar algunas como completadas
   - Eliminar una tarea

5. **Verifica persistencia:** Recarga la pagina (`Ctrl+R`). Las tareas deben seguir ahi — IndexedDB persiste entre sesiones

### Paso 4 — Verificar cuota de almacenamiento

1. Agrega un metodo al `TareaStoreService`:
   ```typescript
   async obtenerCuota(): Promise<{ usado: string; disponible: string; porcentaje: string }> {
     const estimate = await navigator.storage.estimate();
     const usado = estimate.usage ?? 0;
     const disponible = estimate.quota ?? 0;
     const porcentaje = disponible > 0 ? ((usado / disponible) * 100) : 0;

     return {
       usado: `${(usado / 1e6).toFixed(1)} MB`,
       disponible: `${(disponible / 1e6).toFixed(1)} MB`,
       porcentaje: `${porcentaje.toFixed(2)}%`,
     };
   }
   ```
2. Llama al metodo desde tu componente y muestra la informacion:
   ```typescript
   // En TareaListComponent, agrega:
   cuota = signal({ usado: '', disponible: '', porcentaje: '' });

   // En ngOnInit, despues de inicializar:
   this.cuota.set(await this.store.obtenerCuota());
   ```
3. En el template, agrega al final:
   ```text
   <!-- HTML: agrega esto al final del container -->
   <p class="cuota">
     Storage: {{ cuota().usado }} / {{ cuota().disponible }} ({{ cuota().porcentaje }})
   </p>
   ```
4. Verifica que el porcentaje es bajo (probablemente <0.01%). Los navegadores otorgan hasta el 60% del disco al origin

### Paso 5 — Implementar cache layer con fallback

1. Genera un servicio que combine API + IndexedDB como fallback:
   ```bash
   ng generate service services/tarea-api
   ```
2. En `src/app/services/tarea-api.service.ts`:
   ```typescript
   import { Injectable, inject } from '@angular/core';
   import { HttpClient } from '@angular/common/http';
   import { firstValueFrom } from 'rxjs';
   import { TareaStoreService, Tarea } from './tarea-store.service';

   @Injectable({ providedIn: 'root' })
   export class TareaApiService {
     private http = inject(HttpClient);
     private store = inject(TareaStoreService);

     async obtenerTareas(): Promise<Tarea[]> {
       try {
         // Intentar obtener de la API
         const tareas = await firstValueFrom(
           this.http.get<Tarea[]>('/api/tareas')
         );

         // Actualizar el cache local
         await this.sincronizarCache(tareas);
         return tareas;

       } catch (error) {
         console.warn('API no disponible, usando cache local:', error);

         // Fallback: devolver datos del cache (IndexedDB)
         return this.store.todas();
       }
     }

     async crearTarea(titulo: string, descripcion: string = ''): Promise<Tarea> {
       // Siempre guardar localmente primero
       const tarea = await this.store.agregar(titulo, descripcion);

       try {
         // Intentar enviar a la API
         await firstValueFrom(
           this.http.post('/api/tareas', tarea)
         );
       } catch {
         console.warn('API no disponible. Tarea guardada localmente.');
       }

       return tarea;
     }

     private async sincronizarCache(tareasDelServidor: Tarea[]): Promise<void> {
       // Limpiar cache local y reemplazar con datos del servidor
       const tareasLocales = this.store.todas();
       for (const local of tareasLocales) {
         await this.store.eliminar(local.id);
       }
       for (const tarea of tareasDelServidor) {
         await this.store.agregar(tarea.titulo, tarea.descripcion);
       }
     }
   }
   ```
3. Prueba el fallback:
   - Con la API corriendo, carga la pagina — debe traer datos de la API y guardarlos en IndexedDB
   - Detiene la API (o bloquea `/api/tareas` en DevTools → Network → Block request URL)
   - Recarga la pagina — debe mostrar los datos del cache (IndexedDB) con un warning en Console
4. Verifica en DevTools → Console que aparece el mensaje `API no disponible, usando cache local`

## Que puede salir mal

- **"Error: No objectStore named 'tareas' exists"** → Si cambiaste la estructura de la base de datos (agregaste un campo, un indice), necesitas incrementar el numero de version en `openDB('mi-app-tareas', 2, { ... })`. El callback `upgrade` solo se ejecuta cuando la version cambia. Para limpiar durante desarrollo, puedes borrar la base de datos en DevTools → Application → IndexedDB → click derecho → Delete database.
- **"Los datos aparecen en IndexedDB pero el signal no se actualiza"** → Verifica que cada operacion CRUD llama a `this.recargar()` al final. El signal `tareas` solo se actualiza cuando se ejecuta `this.tareas.set(...)` dentro de `recargar()`.
- **"Las tareas se duplican al recargar"** → Si usas `agregar()` en `sincronizarCache`, se generan nuevos IDs. Usa `db.put()` directamente con las tareas del servidor (que ya tienen ID) en vez de pasar por `agregar()`.
- **"QuotaExceededError al guardar datos"** → El storage esta lleno. Implementa una limpieza de datos antiguos. Para desarrollo, puedes borrar la base de datos en DevTools.
