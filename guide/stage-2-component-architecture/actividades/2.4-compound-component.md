## Por que esta actividad

Los compound components son un patrón que usan todas las bibliotecas de UI profesionales (Angular Material, Radix UI, Headless UI). En lugar de crear un único componente `<Tabs>` con 20 props para configurar todo, creas multiples componentes (`<Tabs>`, `<TabList>`, `<Tab>`, `<TabPanel>`) que comparten estado implicitamente. Esto le da al consumidor control sobre la estructura sin que necesite manejar el estado interno. Aprender este patrón te prepara para construir componentes flexibles y para entender como funcionan las bibliotecas que usaras en produccion.

## Antes de empezar

Necesitas haber completado las **Actividades 2.2 y 2.3** (composicion de componentes y servicios).

**¿Que es un compound component?** Es un grupo de componentes que trabajan juntos compartiendo estado de forma implicita. El ejemplo clásico es `<select>` y `<option>` en HTML: el `<select>` maneja el estado (que opción esta seleccionada) y los `<option>` son los hijos que participan. Tu no le dices al `<select>` "el segundo option esta seleccionado" — el `<select>` lo maneja internamente.

**¿Que es content projection?** Es el mecanismo de Angular para que un componente padre pueda inyectar contenido dentro de un componente hijo. Se hace con `<ng-content />` en el template del hijo. Es como un "espacio reservado" donde el padre pone lo que quiera.

**¿Por que navegación con teclado?** Porque no todos los usuarios usan mouse. Las personas que usan lectores de pantalla, o que tienen discapacidades motrices, navegan con teclado. Los tabs deben ser navegables con las flechas izquierda/derecha segun el patrón WAI-ARIA.

### Paso 1 — Crear el servicio de estado compartido

1. Genera el servicio:
   ```bash
   ng g service services/tabs-state
   ```

2. Abre `src/app/services/tabs-state.service.ts` y reemplaza por:
   ```typescript
   import { Injectable, signal } from '@angular/core';

   @Injectable()
   export class TabsStateService {
     activeIndex = signal(0);
     tabCount = signal(0);

     selectTab(index: number) {
       this.activeIndex.set(index);
     }

     registerTab() {
       this.tabCount.update(count => count + 1);
       return this.tabCount() - 1;
     }

     selectNext() {
       const next = (this.activeIndex() + 1) % this.tabCount();
       this.activeIndex.set(next);
     }

     selectPrevious() {
       const prev = (this.activeIndex() - 1 + this.tabCount()) % this.tabCount();
       this.activeIndex.set(prev);
     }
   }
   ```

> 💡 **Nota:** Este servicio NO tiene `providedIn: 'root'`. Lo vamos a proveer a nivel del componente `TabGroup`, para que cada grupo de tabs tenga su propia instancia de estado. Esto es clave: si fuera global, todos los tabs de la página compartiran el mismo estado.

### Paso 2 — Crear el componente TabGroup

1. Genera el componente:
   ```bash
   ng g c tab-group
   ```

2. Abre `src/app/tab-group/tab-group.component.ts` y reemplaza por:
   ```typescript
   import { Component } from '@angular/core';
   import { TabsStateService } from '../services/tabs-state.service';

   @Component({
     selector: 'app-tab-group',
     standalone: true,
     providers: [TabsStateService],
     template: `<ng-content />`,
   })
   export class TabGroupComponent {}
   ```

> 💡 **Nota:** `providers: [TabsStateService]` crea una instancia del servicio que solo es visible para este componente y sus hijos. Es como crear un "contexto" en React.

### Paso 3 — Crear el componente Tab

1. Genera el componente:
   ```bash
   ng g c tab
   ```

2. Abre `src/app/tab/tab.component.ts` y reemplaza por:
   ```typescript
   import { Component, inject, input, OnInit } from '@angular/core';
   import { TabsStateService } from '../services/tabs-state.service';

   @Component({
     selector: 'app-tab',
     standalone: true,
     templateUrl: './tab.component.html',
     styleUrl: './tab.component.css',
     host: {
       'role': 'tab',
       '[attr.aria-selected]': 'isActive()',
       '[attr.tabindex]': 'isActive() ? 0 : -1',
       '(click)': 'select()',
       '(keydown.ArrowRight)': 'tabsState.selectNext()',
       '(keydown.ArrowLeft)': 'tabsState.selectPrevious()',
     },
   })
   export class TabComponent implements OnInit {
     label = input.required<string>();
     tabsState = inject(TabsStateService);
     index = -1;

     ngOnInit() {
       this.index = this.tabsState.registerTab();
     }

     isActive() {
       return this.tabsState.activeIndex() === this.index;
     }

     select() {
       this.tabsState.selectTab(this.index);
     }
   }
   ```

3. Abre `src/app/tab/tab.component.html` y reemplaza por:
   ```text
   <!-- HTML: template del tab -->
   {{ label() }}
   ```

4. Abre `src/app/tab/tab.component.css` y agrega:
   ```css
   :host {
     padding: 0.75rem 1.5rem;
     cursor: pointer;
     border: none;
     border-bottom: 3px solid transparent;
     background: none;
     font-size: 1rem;
     display: inline-block;
   }

   :host[aria-selected='true'] {
     border-bottom-color: #2563eb;
     color: #2563eb;
     font-weight: bold;
   }

   :host:focus-visible {
     outline: 2px solid #2563eb;
     outline-offset: -2px;
   }
   ```

### Paso 4 — Crear el componente TabPanel

1. Genera el componente:
   ```bash
   ng g c tab-panel
   ```

2. Abre `src/app/tab-panel/tab-panel.component.ts` y reemplaza por:
   ```typescript
   import { Component, inject, input } from '@angular/core';
   import { TabsStateService } from '../services/tabs-state.service';

   @Component({
     selector: 'app-tab-panel',
     standalone: true,
     template: `
       @if (isActive()) {
         <div role="tabpanel">
           <ng-content />
         </div>
       }
     `,
   })
   export class TabPanelComponent {
     index = input.required<number>();
     private tabsState = inject(TabsStateService);

     isActive() {
       return this.tabsState.activeIndex() === this.index();
     }
   }
   ```

### Paso 5 — Usar los tabs en la app

1. Abre `src/app/app.component.ts` y actualiza:
   ```typescript
   import { Component } from '@angular/core';
   import { TabGroupComponent } from './tab-group/tab-group.component';
   import { TabComponent } from './tab/tab.component';
   import { TabPanelComponent } from './tab-panel/tab-panel.component';

   @Component({
     selector: 'app-root',
     standalone: true,
     imports: [TabGroupComponent, TabComponent, TabPanelComponent],
     templateUrl: './app.component.html',
   })
   export class AppComponent {}
   ```

2. Abre `src/app/app.component.html` y reemplaza por:
   ```text
   <!-- HTML: uso de los compound components Tabs -->
   <main style="padding: 2rem;">
     <h1>Compound Component: Tabs</h1>

     <app-tab-group>
       <div role="tablist" style="border-bottom: 1px solid #e5e7eb;">
         <app-tab label="Perfil" />
         <app-tab label="Configuracion" />
         <app-tab label="Notificaciones" />
       </div>

       <app-tab-panel [index]="0">
         <h2>Mi Perfil</h2>
         <p>Aqui va el contenido del perfil del usuario.</p>
       </app-tab-panel>

       <app-tab-panel [index]="1">
         <h2>Configuracion</h2>
         <p>Opciones de configuracion de la cuenta.</p>
       </app-tab-panel>

       <app-tab-panel [index]="2">
         <h2>Notificaciones</h2>
         <p>Preferencias de notificaciones.</p>
       </app-tab-panel>
     </app-tab-group>
   </main>
   ```

3. Guarda y verifica en el navegador: deberas ver 3 tabs. Al hacer clic en cada uno, el panel correspondiente se muestra.

### Paso 6 — Agregar navegación por teclado

La navegación por teclado ya esta configurada en el decorador `host` del componente `Tab`:
- `(keydown.ArrowRight)` → selecciona el siguiente tab
- `(keydown.ArrowLeft)` → selecciona el tab anterior

Pruebalo:
1. En el navegador, haz clic en el primer tab
2. Presiona la flecha derecha → el segundo tab se activa
3. Presiona la flecha derecha → el tercer tab se activa
4. Presiona la flecha derecha → vuelve al primer tab (es circular)
5. Presiona la flecha izquierda → vuelve al tercer tab

### Paso 7 — Probar reordenamiento

El poder de un compound component es que los hijos se pueden reordenar sin romper la funcionalidad.

1. En `app.component.html`, cambia el orden de los tabs:
   ```text
   <!-- HTML: tabs reordenados -->
   <div role="tablist" style="border-bottom: 1px solid #e5e7eb;">
     <app-tab label="Notificaciones" />
     <app-tab label="Perfil" />
     <app-tab label="Configuracion" />
   </div>

   <app-tab-panel [index]="0">
     <h2>Notificaciones</h2>
     <p>Preferencias de notificaciones.</p>
   </app-tab-panel>

   <app-tab-panel [index]="1">
     <h2>Mi Perfil</h2>
     <p>Aqui va el contenido del perfil del usuario.</p>
   </app-tab-panel>

   <app-tab-panel [index]="2">
     <h2>Configuracion</h2>
     <p>Opciones de configuracion de la cuenta.</p>
   </app-tab-panel>
   ```
2. Verifica que los tabs siguen funcionando correctamente con el nuevo orden
3. **Deshaz el cambio** para dejar los tabs en el orden original

## Que puede salir mal

- **"NullInjectorError: No provider for TabsStateService"** → El servicio no se encuentra porque no esta provisto. Asegurate de que `TabGroupComponent` tiene `providers: [TabsStateService]` y que los componentes `Tab` y `TabPanel` son hijos de `TabGroup` en el template.
- **"Todos los tabs estan activos al mismo tiempo"** → Verifica que cada `TabPanel` tiene un `[index]` diferente (0, 1, 2) y que el servicio `TabsStateService` no esta en `providedIn: 'root'`.
- **"Las flechas del teclado no hacen nada"** → El tab necesita tener foco. Haz clic en un tab primero, luego usa las flechas. Verifica que `host` tiene los bindings `(keydown.ArrowRight)` y `(keydown.ArrowLeft)`.
- **"No veo el focus ring al navegar con teclado"** → Verifica que el CSS tiene `:host:focus-visible` y que no hay ningun CSS global que oculte los outlines (`outline: none`).

## Resultado esperado

En el navegador ves 3 tabs. Al hacer clic en cada uno, se muestra su panel correspondiente. Las flechas izquierda/derecha del teclado cambian el tab activo. El tab activo tiene una linea azul debajo y texto en negrita. Los tabs se pueden reordenar en el HTML sin romper la funcionalidad.

**Criterios de aceptacion:**
- [ ] Las flechas Izquierda/Derecha cambian el tab activo (navegación circular)
- [ ] Reordenar los componentes `Tab` y `TabPanel` en el template no rompe la funcionalidad
- [ ] El tab activo tiene un indicador visual (focus visible) accesible por teclado

**Pilares de diseño que ejercita esta actividad:**
- **Mantenibilidad** — el patrón compound component permite extender los tabs sin modificar el componente base (OCP)
- **Accesibilidad** — navegación por teclado y roles ARIA (`role="tab"`, `role="tablist"`, `role="tabpanel"`)
- **Usabilidad** — el consumidor controla la estructura; el componente gestiona el comportamiento
