### Paso 1 — Verificar Core Web Vitals (5.1)

1. Abre Chrome DevTools → Lighthouse
2. Ejecuta Performance en modo Mobile
3. Verifica:
   - [ ] Performance >= 90
   - [ ] LCP < 2.5s
   - [ ] CLS = 0

Si alguno falla, regresa a la [Actividad 5.1](./5.1-core-web-vitals.md) y corrige.

### Paso 2 — Verificar lazy loading (5.2)

1. Ejecuta el build:
   ```bash
   ng build
   ```
2. Verifica en la salida que hay **Lazy chunk files** ademas de **Initial chunk files**:
   - [ ] Cada ruta tiene su propio chunk
3. Abre tu app y ve a DevTools → Elements
4. Busca la imagen hero:
   - [ ] NO tiene `loading="lazy"`
   - [ ] Tiene `fetchpriority="high"`
5. Busca imagenes below-the-fold:
   - [ ] Tienen `loading="lazy"`

### Paso 3 — Verificar bundle (5.3)

1. Ejecuta el bundle analyzer:
   ```bash
   npm run analyze
   ```
2. Verifica:
   - [ ] Puedes nombrar las 3 dependencias mas grandes
   - [ ] Al menos una optimización fue aplicada
   - [ ] El archivo `bundle-analisis.md` documenta antes vs despues

### Paso 4 — Verificar virtualizacion (5.4)

*(Solo si completaste la Actividad 5.4)*

1. Abre la lista de 10,000 elementos
2. DevTools → Performance → graba scroll rápido
3. Verifica:
   - [ ] FPS se mantiene en ~60 durante el scroll
   - [ ] En DevTools → Elements, solo hay ~20 elementos, no 10,000

### Paso 5 — Verificar memoizacion (5.5)

*(Solo si completaste la Actividad 5.5)*

1. Abre el componente con memoizacion
2. Abre Console
3. Interactua con controles que NO afectan la lista filtrada (ej: el botón contador)
4. Verifica:
   - [ ] El `computed()` NO se recalcula cuando datos no relacionados cambian
   - [ ] El inline object esta reemplazado por un signal

### Paso 6 — Verificar medicion real (5.6)

*(Solo si completaste la Actividad 5.6)*

1. Abre la consola y navega la app
2. Verifica:
   - [ ] `web-vitals` reporta metricas en la consola
   - [ ] El archivo `medicion-real-vs-sintetico.md` documenta las discrepancias

## Que puede salir mal

- **"Lighthouse ahora me da un score menor que antes"** → Es posible si agregaste funcionalidad nueva entre actividades. Revisa que no hayas agregado imagenes sin dimensiones o imports pesados nuevos.
- **"Los chunks lazy no aparecen en el build"** → Verifica que no tienes imports estaticos de los componentes lazy en ningun archivo. Un solo `import { MiComponente }` estatico fuerza al bundler a incluirlo en main.js.
